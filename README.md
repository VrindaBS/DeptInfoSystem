
# Department News System

A web application to manage and display department-level notifications and club updates for students and admins.

## Features
- Department-wise and club-specific announcements
- Admin login/signup to manage notifications
- Frontend using HTML, CSS, EJS
- Backend powered by Node.js, Express.js
- MongoDB for database integration

## How to Run
1. Clone the repository  
2. Run `npm install` to install dependencies  
3. Set up MongoDB and update the connection URL  
4. Start the server using `node server.js`  
5. Open `http://localhost:3000` in your browser
